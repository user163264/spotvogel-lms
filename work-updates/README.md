## Development Standards

Team members should keep these work updates current by:
1. Creating detailed documentation after completing significant work
2. Including specific file paths and line numbers for changes
3. Explaining the reasoning behind implementation choices
4. Identifying any challenges or blockers
5. Responding to team members' updates

This documentation serves as both a knowledge base and communication channel for the development team.
